# BirkNext User Guide

## Overview
BirkNext helps teams transform specifications into structured scenarios using deterministic extraction.

## Main Workflow
1. Paste specification text
2. Extract candidate scenarios
3. Review extracted items
4. Select desired scenarios
5. Save selected scenarios

## Scenario Types
- REQUIREMENT
- TEST
- NEEDS_CLARIFICATION

## Key Principles
- Nothing is auto-saved
- Extraction is deterministic
- Raw specification text is not logged
- Users stay in control
